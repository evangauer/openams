# OpenAMS brand

Logo, color, type and social assets for OpenAMS.

- [`BRAND.md`](BRAND.md): how to write the name, use the logo, apply color and type, and
  show the Relay connection.
- [`index.html`](index.html): every asset on one page. Open it in a browser.
- [`tokens.css`](tokens.css) and [`tailwind-theme.css`](tailwind-theme.css): design tokens
  for the app and the website, light and dark.

| Folder | Contents |
| --- | --- |
| `logo/` | Mark, wordmark and horizontal and stacked lockups, in full color, inverse and one color |
| `icons/` | Favicons, app icons and the web manifest |
| `readme/` | README header (dark, used on both GitHub themes) and a light variant |
| `social/` | GitHub social preview, OG image and template, avatar, X and LinkedIn banners |
| `badges/` | "Works with Relay" badge |
| `scenes/` | Sundown pixel scenes for the website, 404 and empty states |
| `scripts/` | Builds every asset from code and checks color contrast |

Fonts are Instrument Sans and JetBrains Mono, both under the SIL Open Font License 1.1.
